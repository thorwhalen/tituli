tituli.tools

The SSOT of dispatchable operations: flat, JSON-able in, JSON-able out.

These are the functions every surface projects: the CLI (python -m tituli) today, an MCP server or HTTP route tomorrow, an agent skill in prose. Nothing here imports a surface library; each function takes paths and strings, writes a file, and returns a dict describing what it wrote.

>>> sorted(f.__name__ for f in _dispatch_funcs)
['calligram', 'caption', 'credits', 'fonts', 'lower_third', 'overlay_video', 'title_card']
tituli.tools.calligram(text: str, *, out: str = 'calligram.png', shape: str = 'wave', size: str | None = None, background: str | None = '#f4f1e8', upright: bool = False, mask: str | None = None, reveal: float | None = None) → dict[source]

Lay text along a shape (circle, wave, arc, an SVG path, rain).

shape="rain" is Apollinaire’s Il pleut (lines become streaks; give it a portrait size). mask (an image path, light = inside) pours the text into a silhouette instead. reveal (seconds) writes an MP4 with a glyph-by-glyph reveal rather than a PNG.

tituli.tools.caption(image: str, text: str, attribution: str = '', *, out: str = 'captioned.png', anchor: str = 'auto', avoid: str | None = 'saliency', delivery: str | None = 'youtube', size: str | None = None, overlay_only: bool = False) → dict[source]

Put a museum-label caption and a tiny attribution on image.

Placement avoids the subject (avoid="saliency" uses burns when installed, otherwise nothing is avoided) and the delivery target’s reserved zones. overlay_only writes a transparent PNG to composite onto motion video instead of the flattened picture.

tituli.tools.credits(spec: str, *, out: str = 'credits.mp4', mode: str = 'crawl', size: str | None = None, speed: float | None = None, hold: float | None = None, background: str | None = None, audio: str | None = None) → dict[source]

Render credits from a JSON spec file (or JSON string) to out.

Spec: {"title": ..., "sections": [{"heading": ..., "entries": [["Role", "Name"], "Name", ...]}], "closing": [...]} — or a plain JSON list of lines. mode is "crawl" (one MP4) or "cards" (PNG per card, or one MP4 when out ends in .mp4). Never truncates.

tituli.tools.fonts(query: str = '') → dict[source]

List installed font families (optionally filtered by substring).

tituli.tools.lower_third(name: str, role: str = '', *, out: str = 'lower_third.png', background: str | None = None, size: str | None = None, delivery: str | None = 'youtube') → dict[source]

A name + role block, bottom-left, as a transparent overlay (or on a picture).

tituli.tools.overlay_video(video: str, overlays: str, *, out: str = 'overlaid.mp4', delivery: str | None = 'youtube') → dict[source]

Composite captions/lower thirds onto a finished video in one ffmpeg pass.

overlays is a JSON file/string: a list of {"start", "end", "text", "attribution"?, "kind"?: "caption"|"lower_third", "role"?, "anchor"?}. Text is laid out against the video’s frame size; the picture under each overlay is not sampled (pass a still through caption for that).

tituli.tools.title_card(title: str, subtitle: str = '', *, out: str = 'title.png', background: str | None = None, size: str | None = None, kicker: str = '', anchor: str = 'center', avoid: str | None = None, duration: float | None = None) → dict[source]

Render a title card to out (PNG, or MP4 when duration is given).

background is a colour (#101014), an image path, or nothing (a transparent overlay). anchor is a grid position; avoid is "saliency" or "x,y,w,h" to keep the title off the subject.
