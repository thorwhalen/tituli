tituli.calligram

Calligrams and concrete poems: text whose shape is part of the meaning.

Three treatments, all producing an ordinary Layout:

  • on_path() — glyphs ride a Path (any shape: circle, wave, Bézier, SVG d), rotated to the tangent or kept upright;

  • rain() — Apollinaire’s Il pleut: upright letters stepping down fanning streaks (a preset of the same machinery, with the 1918 measurements as defaults);

  • in_shape() — prose poured into a silhouette, the concrete-page case.

shape= accepts a named preset, an SVG path string, or a Path, so a caller can say "circle" and a designer can hand over a traced outline — the same seam.

>>> from tituli.frame import Frame
>>> lay = on_path("round and round", shape="circle", frame=Frame.blank((800, 800)))
>>> len(lay.runs) == len("round and round".replace(" ", ""))
True

tituli.calligram.rain(lines: Sequence[str] | str, *, frame: Frame, style: TextStyle = TextStyle(family=('Georgia', 'Palatino', 'Baskerville', 'Liberation Serif', 'DejaVu Serif', 'Times New Roman'), size=0.035, weight=400, italic=False, condensed=False, color=(17, 17, 17), tracking=0.0, leading=1.2, case='as-is', align='left', opacity=1.0), box: Box | None = None, slants: Sequence[float] = (0.186, 0.22, 0.257, 0.298, 0.353), head_offsets: Sequence[float] = (0.0, 7.0, 11.7, 16.4, 19.3), size_ratio: float = 0.86) → Layout[source]

Il pleut: each line a streak of upright letters falling across the frame.

Wants a portrait frame. slants (dx per step down) and head_offsets (where each streak starts, in slot units) are shape parameters, not coordinates — the defaults are Apollinaire’s.

tituli.calligram.resolve_shape(shape: str | Path, box: Box) → Path[source]

Turn a name, an SVG d string or a Path into a Path fitted to box.

Names: "line", "circle", "arc", "wave", "diagonal", "s-curve". Anything starting with M/m is parsed as SVG.
