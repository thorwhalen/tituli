tituli.fonts¶

Font discovery with no bundled fonts.

tituli never ships a typeface (licensing), so a typeface request — a family name, weight and slant — is resolved against the fonts already installed on the machine, and falls back to the scalable face Pillow embeds (Aileron). That fallback is a real font, not a stub, so every render works out of the box on a bare CI runner; it just looks better on a machine with Helvetica Neue.

Resolution order is a preference list: the first family found wins.

>>> face = resolve_face(["No Such Family", "DejaVu Sans"], size=48)
>>> face.size
48
>>> face.family in ("DejaVu Sans", "Aileron") or isinstance(face.family, str)
True
