tituli.shaping

Optional engine: HarfBuzz shaping + FreeType rendering (pip install tituli[shaping]).

The Pillow default handles Latin text well and rotates glyph bitmaps. This engine shapes the run with HarfBuzz (kerning, ligatures, Arabic/Devanagari joining) and asks FreeType to apply the rotation to the outline before rasterising, which is the typographically correct order. Same Run in, same canvas out — it is the engine= seam of tituli.render.render().

Import cost is paid only when constructed; the module itself imports nothing optional at top level.
